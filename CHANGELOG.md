# Журнал изменений

## 2026-11-03 — первая рабочая версия

- Найдена и исследована книга `ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xlsx` именно в этом репозитории; документированы все 80 формул, зависимости, вводимые ячейки, категории и неоднозначности.
- Реализованы квартальные и годовые расчёты с Decimal, включая исходную особую формулу H15, отдельный H17, фиксированные ставки 20%, отрицательные налоговые значения и явное деление на ноль.
- Добавлено локальное приложение для Windows: организации, ручной ввод периодов, статьи затрат, графики, сравнение сопоставимых кварталов, CSV и согласованная SQLite-копия. Исходные значения намеренно не импортируются.
- Добавлены изолированное хранение, транзакции и защита локального сервера; исходные данные пользователя и резервные копии не генерируются в репозитории.
- Созданы документация, полная воспроизводимая инвентаризация книги и тесты, проверяющие все 80 сохранённых результатов Excel, хранилище, HTTP, экспорт и пользовательские сценарии в браузере.
- Настроена автоматическая GitHub Actions-сборка Windows x64 при push, pull request и вручную, с проверкой исполняемого файла и публикацией артефакта.
