# Зафиксированные решения владельца

Дата: 2026-11-03.

1. Исходник для этого проекта — книга в репозитории `analiz`, а не похожие файлы в других репозиториях. Год и организация в книге не указаны.
2. Годовой вычет сохраняется **по исходной формуле H15**, не заменяется суммой квартальных вычетов. При этом приложение отдельно показывает сумму и разницу, а H17 оставлен суммой кварталов.
3. **Пока без импорта**: программа предназначена для ручного ввода. Существующие суммы из Excel не назначаются никакому году и не переносятся в новую базу. Резервная копия — отдельный механизм защиты уже введённых пользователем данных, не импорт исходной таблицы.
4. НДС и налог на прибыль — **фиксированные 20%**, как в книге; настройки ставок для будущих лет не добавлять без нового решения владельца.
5. Указание владельца: если что-то непонятно, **не додумывать, а спросить**. В частности, не объявлять значения столбца C ставками и не предполагать валюту или год исходных сумм.

Рабочие расширения, не меняющие эти решения: несколько организаций, новые статьи затрат, CSV-отчёт, резервная копия, сравнение одинаковых кварталов и графики. При добавлении статей годовые итоги рассчитываются для всех статей, в отличие от пустых H48:H55 исходного шаблона; это описано в анализе книги.
