# Зафиксированные решения владельца

Дата: 2026-11-03. Если что-то существенно неясно, **спросить, не додумывать**.

1. Источник — `ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xlsx` в репозитории `analiz`, не похожий файл в другом репозитории. Год, организация и валюта оригинала не указаны: не угадывать их и не импортировать автоматически.
2. Годовой вычет сохраняется **по исходной формуле H15**, не заменяется суммой квартальных вычетов. Приложение отдельно показывает сумму и разницу; H17 остаётся суммой кварталов. Ноль в знаменателе и отрицательный налог не маскировать.
3. Первоначальное решение «пока без импорта» владелец **изменил**: нужны импорт оригинальной книги и ранее выгруженного отчёта и экспорт для **одной выбранной организации и года**. Выбор назначения и замены существующих периодов должен быть явным.
4. Общие константы НДС и налога на прибыль в формулах — **фиксированные 20%**, как в книге; настройку этих констант не добавлять без нового решения.
5. Владелец подтвердил: `C20:C47` — ставки НДС по статьям; `25` в C31 — тоже ставка НДС. Их показывать и хранить по годам, но **не выводить из них входящий НДС** и не изменять формулы книги: общий входящий НДС вводится вручную.
6. Для безубыточности владелец выбрал: себестоимость реализации — переменные затраты; пользователь сам определяет тип остальных статей. Не размечать их по предположению; ненулевые неразделённые расходы блокируют порог.
7. Сохранить понравившийся стиль, но расположить **все разделы на одной странице без переключения левых вкладок**; четыре квартала и итог должны быть видны вместе. Добавить подробную аналитику и её оценку.

Рабочие расширения без изменения правил: несколько организаций, дополнительные статьи, CSV, резервная копия, сравнение одинаковых кварталов и графики. Дополнительные статьи суммируются за год, в отличие от пустых H48:H55 исходного шаблона.
