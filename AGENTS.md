# Инструкции следующему агенту

1. Прочитайте [README](README.md), [решения владельца](docs/decisions.md), [анализ книги](docs/workbook-analysis.md) и [архитектуру](docs/architecture.md). Если требования или бухгалтерский смысл неясны — **спросите владельца**, не угадывайте.
2. Импорт оригинальной книги и собственного XLSX разрешён только после явного выбора организации/года и подтверждения режима замены. Не угадывайте организацию, год или валюту исходных сумм, не загружайте их автоматически.
3. Общие ставки формул НДС и налога на прибыль фиксированы на 20%. H15 и H17 следуют исходной книге, включая деление на ноль и возможный отрицательный налог. C20:C47 — подтверждённые владельцем ставки НДС статей, включая C31=25%; не использовать их для автоматического расчёта вводимого входящего НДС.
4. Себестоимость реализации относится к переменным затратам. Тип прочих статей определяет пользователь, не алгоритм; без разметки всех ненулевых статей точку безубыточности не выводить. Все кварталы, итог, аналитика и графики — на одной странице.
5. Не публикуйте новые финансовые данные, SQLite-базы или резервные копии. Книга уже есть в публичном репозитории; дополнительных копий не создавайте. Сохраняйте существующие данные и тестируйте миграции.
6. Проверки: `python scripts/audit_workbook.py --check`, `python -m pytest -q`, `npm ci && npm run test:ui`, `python app.py --self-test`. UI-тест использует Chrome/Edge и временную БД. Для работы из исходников установить `requirements.txt`.
7. Если книга изменилась, сравните все формулы и зависимости до обновления fingerprint или `docs/workbook-formulas.md`; не меняйте их вслепую ради CI. Обновляйте `CHANGELOG.md` и документацию.
8. GitHub Actions автоматически тестирует каждый push и собирает Windows x64; проверяйте запуск и артефакт. Работайте в назначенной ветке, не предполагайте, что можно писать в `main`.
