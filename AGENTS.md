# Инструкции следующему агенту

1. Прочитайте [README](README.md), [решения владельца](docs/decisions.md), [анализ книг](docs/workbook-analysis.md) и [архитектуру](docs/architecture.md). Если требования или бухгалтерский смысл неясны — **спросите владельца**, не угадывайте.
2. Актуальный источник — `ОТЧЕТ ПО ОРГАНИЗАЦИИ мир 2.xlsx` именно из этого репозитория. Инвентаризация — [84 формулы](docs/workbook-2-formulas.md); прежняя книга с [80 формулами](docs/workbook-formulas.md) сохраняется для истории. Различаются только D15:G15. Импорт обеих книг и отчётов V2/V3 разрешён после явного выбора организации/года и режима; не угадывать год, организацию или валюту, не загружать автоматически.
3. D15:G15 — накопительные формулы новой книги для **всех лет**, H15 — `H14/H10*H16`, H17 — сумма D17:G17. Не маскировать #ДЕЛ/0!, проверять его распространение; сохранять старые ручные вычеты в `legacy_manual_deduction`, но не использовать в расчётах. Миграции v1/v2→v3 не должны терять данные, резервная копия рекомендуется перед обновлением.
4. Общие константы НДС и налога на прибыль фиксированы на 20%; отрицательные результаты не обнуляются. C20:C47 — подтверждённые ставки НДС статей, включая C31=25%; не использовать их для автоматического расчёта вводимого входящего НДС.
5. Себестоимость реализации — переменная; тип прочих статей определяет пользователь, не алгоритм. Все кварталы, итог, аналитика и графики — на одной странице. Прежние CSS-размеры шрифтов увеличены **в 2 раза**, а не в 1,5.
6. На горизонтальном графике структуры знаменатель — все статьи + налог НДС + налог на прибыль, **без себестоимости реализации**. Выбор статей слева не меняет знаменатель; отрицательные значения сохраняют знак, при неположительном/неопределённом знаменателе проценты недоступны. Не изменять формулы прибыли. Архивирование скрывает статью без потери истории; необратимое удаление требует показа всех затронутых лет, подтверждения и проверки ревизии.
7. Не публикуйте новые финансовые данные, SQLite-базы или резервные копии. Существующие книги уже в публичном репозитории; дополнительных копий не создавайте. Сохраняйте данные и тестируйте миграции.
8. Проверки: `python scripts/audit_workbook.py --check`, `python -m pytest -q`, `npm ci && npm run test:ui`, `python app.py --self-test`. UI-тест использует Chrome/Edge и временную БД. При изменении книги исследуйте все формулы и зависимости до обновления fingerprint; не меняйте его вслепую ради CI.
9. GitHub Actions автоматически тестирует каждый push и собирает Windows x64; проверяйте запуск и артефакт. Работайте в назначенной ветке, не предполагайте, что можно писать в `main`. Обновляйте CHANGELOG и документацию.
