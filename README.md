# Анализ организаций

Локальная Windows-программа для анализа продаж, себестоимости, затрат, прибыли и НДС. Таблица с четырьмя кварталами и итогом, оценки и графики расположены на одной странице. Расчёты основаны на книге **«ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xlsx»** из этого репозитория.

> Исходные суммы **не загружаются автоматически**: в книге не указаны год, организация и валюта. Можно вводить данные вручную или самостоятельно выбрать организацию и год и подтвердить импорт Excel. Для повседневной работы интернет не требуется.

## Скачать и запустить в Windows

1. Откройте [GitHub → Actions → Build Windows application](https://github.com/slchumak75-sketch/analiz/actions/workflows/build-windows.yml) и выберите последний **успешный** запуск нужной ветки.
2. В разделе **Artifacts** скачайте `AnalizOrganizaciy-Windows-x64`, распакуйте ZIP и запустите `AnalizOrganizaciy.exe` на Windows x64. Python устанавливать не нужно. Несколько секунд может занять первый запуск.
3. Программа откроется в стандартном современном браузере по локальному адресу `127.0.0.1`. Создайте организацию и выберите год; подпись валюты необязательна и не выполняет конвертацию.
4. В таблице доступны все кварталы сразу. Для каждого заполняемого квартала укажите семь основных показателей из строк 8, 9, 12, 14, 15, 16 и 18. Для отсутствующего показателя введите `0` или нажмите **«+ нули»** в заголовке квартала; пустые статьи затрат равны нулю. Нажмите **«Сохранить»**.
5. Для каждой статьи с ненулевыми затратами выберите на этот год **постоянные** или **переменные** затраты и сохраните: это нужно для расчёта безубыточности. Статьи можно добавлять и архивировать без удаления истории.
6. Ниже таблицы находятся оценки, подробные показатели, графики кварталов, налогов, структуры затрат и истории. Для завершения нажмите значок выхода в верхней панели и закройте вкладку.

Сборка не подписана цифровой подписью: Windows SmartScreen может показать предупреждение. Скачивайте артефакт только из этого репозитория и ожидаемого запуска.

## Импорт и экспорт Excel

Обмен относится **только к выбранной организации и году**, не ко всей базе. Поддерживаются исходная книга из репозитория и ранее выгруженный программой `.xlsx`. Перед заменой данных рекомендуется скачать резервную копию.

1. Выберите или создайте организацию, укажите год и сохраните несохранённые изменения. Нажмите **«Загрузить Excel»** и выберите `.xlsx`.
2. В проверке показаны выбранные организация, год и валюта, кварталы файла, новые статьи и, если они есть, данные из собственного отчёта. Исходная книга не содержит организации, года и валюты: приложение их не угадывает. Конвертация валют не выполняется.
3. Существующие кварталы по умолчанию **пропускаются**. Можно явно выбрать их замену. Кварталы, которых нет в файле, не удаляются. Флажок применения ставок НДС и типов затрат влияет на **весь выбранный год**, включая ранее сохранённые кварталы; для уже заполненного года он по умолчанию выключен. В исходной книге типы затрат отсутствуют — прежняя классификация не стирается.
4. Проверьте назначение, установите флажок подтверждения и нажмите **«Загрузить данные»**. Импорт атомарен. Название и валюта организации, а также архивный статус её статей не меняются автоматически. Новые и совпадающие статьи сопоставляются с проверкой идентификаторов/названий; неоднозначные совпадения отклоняются.
5. **«Выгрузить Excel»** создаёт книгу с листом в исходном порядке, формулами, листом аналитики и двумя диаграммами. Excel пересчитывает формулы при открытии, но аналитика и диаграммы — **снимок на момент выгрузки**. После правок загрузите и выгрузите отчёт заново. Новые статьи добавляйте в конце: их суммы будут учтены в формулах после повторного импорта и экспорта. Имеющиеся статьи нельзя переименовывать или переставлять из-за служебных идентификаторов.

Импортируются **только входные числовые значения**, а не сохранённые результаты расчётных формул. Формулы во входных ячейках, макросы и внешние связи отклоняются; `.xls` и `.xlsm` не поддерживаются. Заполненный квартал должен содержать все семь основных показателей; пустой квартал остаётся отсутствующим. Пределы: 10 МиБ файла, 80 МиБ после распаковки и 1000 статей.

Excel сохраняет не более 15 значащих цифр числа. Чтобы не потерять точность при обратном импорте, экспорт будет отменён с пояснением, если **входное** значение превышает этот предел. Резервная копия SQLite сохраняет все исходные цифры; CSV содержит полную расчётную точность, но сам по себе не является резервной копией.

## Правила расчёта

- Общие ставки формул НДС и налога на прибыль — фиксированные **20%**, как в исходной книге. Это не автоматическое определение налоговых ставок.
- По подтверждению владельца `C20:C47` — ставки НДС отдельных статей, включая **25% в C31**. Они отображаются и могут задаваться на год, но **не** пересчитывают общий входящий НДС: он по-прежнему вводится вручную.
- Годовой вычет H15 = `H14 / H10 × H16`, а не сумма квартальных вычетов. Показаны обе величины и их разница. H17 остаётся суммой квартальных значений. При нулевой выручке H15 не определён (`#ДЕЛ/0!`).
- При убытке исходная формула может дать отрицательный налог на прибыль; программа не подменяет его нулём и предупреждает об этом. Отрицательный НДС также возможен.
- `Выручка без НДС = выручка с НДС − начисленный НДС`. Себестоимость реализации считается переменной; остальные расходы классифицирует пользователь. `Маржинальный доход = выручка без НДС − переменные затраты`; `точка безубыточности = постоянные затраты / (маржинальный доход / выручка без НДС)`. Запас прочности — разница между фактической выручкой без НДС и порогом.
- Порог **не** вычисляется, если есть ненулевые неразделённые статьи, неположительная выручка или маржинальный доход, либо отрицательные постоянные затраты. Расчёт предполагает сохранение структуры продаж и затрат выбранного периода, а не прогнозирует будущее.
- Сравнение с прошлым годом ведётся только по совпадающему набору кварталов. Несохранённый квартал отличается от сохранённого нулевого; неполные годы на графике отмечены `n/4`.
- Данные хранятся как десятичные числа без промежуточного округления. В таблице суммы отображаются с двумя знаками, разница годовых вычетов — до восьми знаков; графики являются числовым приближением.

Программа воспроизводит управленческую таблицу, **не проверяет соответствие текущему налоговому законодательству** и не заменяет бухгалтерскую или налоговую отчётность.

## Хранение и резервное копирование

База находится в `%APPDATA%\AnalizOrganizaciy\analiz.sqlite3`; рядом временно могут появляться `-wal` и `-shm`. До обновления со старой версии рекомендуется сделать резервную копию: схема v1 автоматически мигрирует в v2, старая программа не откроет новую схему.

Нажмите значок замка в верхней панели или **«Резервная копия»** внизу страницы и сохраните `analiz-backup.sqlite3` в безопасном месте. Копия включает WAL и все организации; не публикуйте её. Для восстановления:

1. Завершите **все** экземпляры программы. Сохраните текущую папку `%APPDATA%\AnalizOrganizaciy` отдельно.
2. Создайте чистую папку `%APPDATA%\AnalizOrganizaciy`, поместите туда резервную копию под именем `analiz.sqlite3`; старых файлов `-wal` и `-shm` в чистой папке быть не должно.
3. Запустите приложение и проверьте данные. CSV не поддерживает восстановление базы.

Исходная книга уже находится в **публичном** репозитории. Если она содержит конфиденциальные сведения, владелец должен отдельно решить вопрос публичного доступа к ней и истории Git; новые базы и резервные копии в репозиторий не добавляются.

## Автоматическая сборка и разработка

`.github/workflows/build-windows.yml` запускается при каждом `push`, pull request и вручную; проверяет формулы, Python-тесты, UI, собирает Windows x64 EXE, выполняет его self-test и сохраняет артефакт на 90 дней. Изменения попадают в сборку только после commit и push; ручной запуск в интерфейсе GitHub доступен после появления workflow в ветке по умолчанию.

Для запуска из исходников нужен Python 3.11+ и зависимости из `requirements.txt` (`openpyxl`, `defusedxml`):

```bash
python -m pip install -r requirements.txt
python app.py
# без открытия браузера; случайный свободный порт:
python app.py --no-browser
# только для разработки / защищённого предпросмотра:
python app.py --host 0.0.0.0 --port 8000 --no-browser --data-dir /tmp/analiz-preview
```

Обычный режим слушает только `127.0.0.1`. Режим `0.0.0.0` открывает сервер для внешних подключений и не предназначен для реальных данных в публичной сети. Папку данных также можно задать через `ANALIZ_DATA_DIR`.

```bash
python -m pip install -r requirements-dev.txt
python scripts/audit_workbook.py --check
python -m pytest -q
npm ci
npm run test:ui           # установленный Chrome/Edge или CHROME_PATH
python app.py --self-test
```
