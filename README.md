# Анализ организаций

Локальная Windows-программа для анализа продаж, себестоимости, затрат, прибыли и НДС. Таблица с четырьмя кварталами и итогом, оценки и график структуры затрат расположены на одной странице. Расчёты основаны на книге **«ОТЧЕТ ПО ОРГАНИЗАЦИИ мир 2.xlsx»** из этого репозитория.

> Исходные суммы **не загружаются автоматически**: в книге не указаны год, организация и валюта. Можно вводить данные вручную или самостоятельно выбрать организацию и год и подтвердить импорт Excel. Для повседневной работы интернет не требуется.

## Скачать и запустить в Windows

1. Откройте [GitHub → Actions → Build Windows application](https://github.com/slchumak75-sketch/analiz/actions/workflows/build-windows.yml) и выберите последний **успешный** запуск нужной ветки.
2. В разделе **Artifacts** скачайте `AnalizOrganizaciy-Windows-x64`, распакуйте ZIP и запустите `AnalizOrganizaciy.exe` на Windows x64. Python устанавливать не нужно. Несколько секунд может занять первый запуск.
3. Программа откроется в стандартном современном браузере по локальному адресу `127.0.0.1`. Создайте организацию и выберите год; подпись валюты необязательна и не выполняет конвертацию.
4. В таблице доступны все кварталы сразу. Для каждого заполняемого квартала укажите шесть основных показателей из строк 8, 9, 12, 14, 16 и 18; вычет в строке 15 вычисляется автоматически. Для отсутствующего показателя введите `0` или нажмите **«+ нули»** в заголовке квартала; пустые статьи затрат равны нулю. Нажмите **«Сохранить»**.
5. Для каждой статьи с ненулевыми затратами выберите на этот год **постоянные** или **переменные** затраты и сохраните: это нужно для расчёта безубыточности. Статьи можно добавлять. Чтобы открыть действия, **наведите курсор на название статьи или нажмите на него** (также работает клавиатура и касание): можно скрыть статью в архив или удалить навсегда; скрытую статью можно восстановить через «Архив статей». Для окончательного удаления программа показывает **все затронутые годы**, требует подтверждения и удаляет историю этой статьи; сделайте резервную копию.
6. Пять заголовков — финансовый результат, продажи/НДС/себестоимость, статьи затрат, безубыточность и график — можно независимо свернуть и развернуть. В каждом открытом разделе таблицы появляется своя шапка с кварталами и их действиями. Состояние запоминается в браузере; скрытые поля продолжают сохраняться. Таблица подстраивается под ширину окна: на узком экране кварталы и итог переносятся в подписанные поля без горизонтальной прокрутки.
7. На единственном графике «Основные статьи затрат» выберите слева названия статей и налогов: столбцы и подсказки показывают **суммы по кварталам**, а не проценты. По прямому выбору владельца график всегда подписан «руб.», даже если валюта организации не указана или задана иначе; **конвертации валют нет**, исходные значения и настройки организации не меняются. Для завершения нажмите значок выхода в верхней панели и закройте вкладку.

Сборка не подписана цифровой подписью: Windows SmartScreen может показать предупреждение. Скачивайте артефакт только из этого репозитория и ожидаемого запуска.

## Импорт и экспорт Excel

Обмен относится **только к выбранной организации и году**, не ко всей базе. Поддерживаются обе исходные книги из репозитория и ранее выгруженный программой `.xlsx` форматов V2/V3. Перед заменой данных рекомендуется скачать резервную копию.

1. Выберите или создайте организацию, укажите год и сохраните несохранённые изменения. Нажмите **«Загрузить Excel»** и выберите `.xlsx`.
2. В проверке показаны выбранные организация, год и валюта, кварталы файла, новые статьи и, если они есть, данные из собственного отчёта. Исходная книга не содержит организации, года и валюты: приложение их не угадывает. Конвертация валют не выполняется.
3. Существующие кварталы по умолчанию **пропускаются**. Можно явно выбрать их замену. Кварталы, которых нет в файле, не удаляются. Флажок применения ставок НДС и типов затрат влияет на **весь выбранный год**, включая ранее сохранённые кварталы; для уже заполненного года он по умолчанию выключен. В исходной книге типы затрат отсутствуют — прежняя классификация не стирается.
4. Проверьте назначение, установите флажок подтверждения и нажмите **«Загрузить данные»**. Импорт атомарен. Название и валюта организации, а также архивный статус её статей не меняются автоматически. Новые и совпадающие статьи сопоставляются с проверкой идентификаторов/названий; неоднозначные совпадения отклоняются.
5. **«Выгрузить Excel»** создаёт книгу с листом в исходном порядке, формулами, листом аналитики, структурой статей с налогами и двумя диаграммами. Excel пересчитывает формулы при открытии, но аналитика и диаграммы — **снимок на момент выгрузки**. После правок загрузите и выгрузите отчёт заново. Новые статьи добавляйте в конце: их суммы будут учтены в формулах после повторного импорта и экспорта. Имеющиеся статьи нельзя переименовывать или переставлять из-за служебных идентификаторов.

Импортируются **только входные числовые значения**, а не сохранённые результаты расчётных формул. Формулы во входных ячейках, макросы и внешние связи отклоняются; `.xls` и `.xlsm` не поддерживаются. Заполненный квартал должен содержать все шесть основных показателей; пустой квартал остаётся отсутствующим. Пределы: 10 МиБ файла, 80 МиБ после распаковки и 1000 статей.

Excel сохраняет не более 15 значащих цифр числа. Чтобы не потерять точность при обратном импорте, экспорт будет отменён с пояснением, если **входное** значение превышает этот предел. Резервная копия SQLite сохраняет все исходные цифры; CSV содержит полную расчётную точность, но сам по себе не является резервной копией.

## Правила расчёта

- Общие ставки формул НДС и налога на прибыль — фиксированные **20%**, как в исходной книге. Это не автоматическое определение налоговых ставок.
- По подтверждению владельца `C20:C47` — ставки НДС отдельных статей, включая **25% в C31**. Они отображаются и могут задаваться на год, но **не** пересчитывают общий входящий НДС: он по-прежнему вводится вручную.
- Вычет строки 15 рассчитывается нарастающим итогом по формулам D15:G15 новой книги для **всех лет**. H15 = `H14 / H10 × H16`; H17 остаётся суммой квартальных значений, а сумма вычетов и её разница с H15 доступны в API. При нулевой выручке за 1-й квартал или нулевой накопленной выручке возникает `#ДЕЛ/0!`, распространяющаяся на зависящие формулы; годовой H15 при этом может быть определён. Пустые кварталы участвуют как пустые ячейки Excel (нули).
- График на странице использует сами квартальные суммы статей, НДС и налога на прибыль, **без себестоимости реализации**. Отрицательные суммы сохраняют знак; отсутствующий квартал и неопределённый НДС отображаются пропуском. Значения статей не пропадают, если общий итог нулевой/отрицательный или НДС не определён. Снятие флажка только скрывает соответствующий ряд столбцов.
- Доли по-прежнему рассчитываются для аналитики и Excel: знаменатель = все статьи затрат + налог НДС + налог на прибыль без себестоимости реализации; архивные суммы включены. При неопределённом НДС или неположительном знаменателе доли не выдаются. Эти расчёты не меняют формулы прибыли.
- При убытке исходная формула может дать отрицательный налог на прибыль; программа не подменяет его нулём и предупреждает об этом. Отрицательный НДС также возможен.
- `Выручка без НДС = выручка с НДС − начисленный НДС`. Себестоимость реализации считается переменной; остальные расходы классифицирует пользователь. `Маржинальный доход = выручка без НДС − переменные затраты`; `точка безубыточности = постоянные затраты / (маржинальный доход / выручка без НДС)`. Запас прочности — разница между фактической выручкой без НДС и порогом.
- Порог **не** вычисляется, если есть ненулевые неразделённые статьи, неположительная выручка или маржинальный доход, либо отрицательные постоянные затраты. Расчёт предполагает сохранение структуры продаж и затрат выбранного периода, а не прогнозирует будущее.
- Сравнение с прошлым годом ведётся только по совпадающему набору кварталов. Несохранённый квартал отличается от сохранённого нулевого; сопоставление использует только введённые периоды.
- Данные хранятся как десятичные числа без промежуточного округления. В таблице суммы отображаются с двумя знаками; графики являются числовым приближением.

Программа воспроизводит управленческую таблицу, **не проверяет соответствие текущему налоговому законодательству** и не заменяет бухгалтерскую или налоговую отчётность.

## Что можно добавить в дальнейшем

Без новых исходных данных можно добавить **динамику доли каждой статьи по годам**, сравнение одноимённых кварталов и вклад статей в изменение затрат или прибыли. Эти графики не сделаны автоматически: они перечислены как варианты дальнейшей работы.

Для анализа по товарам, среднему чеку, покупателям, магазинам, количеству продаж, плану или прогнозу нужны соответствующие дополнительные данные и согласованные правила. Приложение не угадывает их по имеющимся суммам.

## Хранение и резервное копирование

База находится в `%APPDATA%\AnalizOrganizaciy\analiz.sqlite3`; рядом временно могут появляться `-wal` и `-shm`. До обновления со старой версии рекомендуется сделать резервную копию: схемы v1 и v2 автоматически мигрируют в v3, старая программа не откроет новую схему. Ранее введённые вручную вычеты сохраняются в базе и не влияют на расчёт. Чтобы увидеть прежнее значение, нажмите подчёркнутую расчётную ячейку соответствующего квартала в строке «Вычет по товарам без НДС»; доступна также клавиатура. При экспорте V3 они сохраняются в скрытых метаданных XLSX. При импорте старый вычет файла добавляется в загружаемый квартал, только если для него ещё нет сохранённого прежнего вычета: существующая история не перезаписывается.

Нажмите значок замка в верхней панели или **«Резервная копия»** внизу страницы и сохраните `analiz-backup.sqlite3` в безопасном месте. Копия включает WAL и все организации; не публикуйте её. Для восстановления:

1. Завершите **все** экземпляры программы. Сохраните текущую папку `%APPDATA%\AnalizOrganizaciy` отдельно.
2. Создайте чистую папку `%APPDATA%\AnalizOrganizaciy`, поместите туда резервную копию под именем `analiz.sqlite3`; старых файлов `-wal` и `-shm` в чистой папке быть не должно.
3. Запустите приложение и проверьте данные. CSV не поддерживает восстановление базы.

Исходная книга уже находится в **публичном** репозитории. Если она содержит конфиденциальные сведения, владелец должен отдельно решить вопрос публичного доступа к ней и истории Git; новые базы и резервные копии в репозиторий не добавляются.

## Автоматическая сборка и разработка

`.github/workflows/build-windows.yml` запускается при каждом `push`, pull request и вручную; проверяет формулы, Python-тесты, UI, собирает Windows x64 EXE, выполняет его self-test и сохраняет артефакт на 90 дней. Изменения попадают в сборку только после commit и push; ручной запуск в интерфейсе GitHub доступен после появления workflow в ветке по умолчанию.

Для запуска из исходников нужен Python 3.11+ и зависимости из `requirements.txt` (`openpyxl`, `defusedxml`):

```bash
python -m pip install -r requirements.txt
python app.py
# без открытия браузера; случайный свободный порт:
python app.py --no-browser
# только для разработки / защищённого предпросмотра:
python app.py --host 0.0.0.0 --port 8000 --no-browser --data-dir /tmp/analiz-preview
```

Обычный режим слушает только `127.0.0.1`. Режим `0.0.0.0` открывает сервер для внешних подключений и не предназначен для реальных данных в публичной сети. Папку данных также можно задать через `ANALIZ_DATA_DIR`.

```bash
python -m pip install -r requirements-dev.txt
python scripts/audit_workbook.py --check
python -m pytest -q
npm ci
npm run test:ui           # установленный Chrome/Edge или CHROME_PATH
python app.py --self-test
```
