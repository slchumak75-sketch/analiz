# Анализ организаций

Локальная Windows-программа для поквартального ведения продаж, себестоимости, затрат, прибыли и показателей НДС. Расчёты основаны на книге **«ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xlsx»** из этого репозитория; графики показывают кварталы, структуру затрат, налоги и динамику по годам.

> Данные из исходной книги **не импортируются автоматически**: год и организация в ней не указаны. По выбору владельца программа начинает работу с пустой базой; показатели вводятся вручную. Библиотека графиков включена в приложение, интернет для работы не нужен.

## Скачать и запустить в Windows

1. Откройте [GitHub → Actions → Build Windows application](https://github.com/slchumak75-sketch/analiz/actions/workflows/build-windows.yml). Выберите последний **успешный** запуск нужной ветки.
2. В разделе **Artifacts** скачайте `AnalizOrganizaciy-Windows-x64`, распакуйте ZIP и запустите `AnalizOrganizaciy.exe` на Windows x64.
3. Программа откроет интерфейс в стандартном современном браузере на локальном адресе `127.0.0.1`. Никакой отдельной установки Python или сервера не требуется. Первый запуск может занять несколько секунд.
4. Создайте организацию, при желании укажите подпись валюты, выберите год и квартал. Заполните семь основных показателей и необходимые статьи затрат, затем нажмите **«Сохранить квартал»**. Для отсутствующего основного показателя вводится `0`; пустая статья затрат считается нулём.
5. Для завершения нажмите **«Завершить работу»** в боковом меню, затем закройте вкладку браузера.

Сборка не подписана цифровой подписью: Windows SmartScreen может показать предупреждение. Убедитесь, что скачиваете артефакт именно из этого репозитория и ожидаемого запуска.

## Что умеет программа

- Несколько организаций, произвольные годы и кварталы; хранение и редактирование истории на одном компьютере.
- Семь вводимых показателей из строк 8, 9, 12, 14, 15, 16 и 18 книги и 28 исходных статей затрат. Можно добавлять и архивировать статьи без удаления их истории. Значения из столбца C книги отображаются как **метки**, а не используются как ставки: в книге у столбца нет заголовка, формулы на него не ссылаются.
- Все расчётные строки 4–19 исходной книги, таблица квартальных и годовых итогов, графики продаж, затрат, прибыли и налогов. Несохранённый квартал не изображается как нулевой.
- Сравнение с прошлым годом только по тем же введённым кварталам, если они есть в обоих годах. На графике многолетней истории неполные годы отмечены `n/4`.
- Выгрузка отчёта в CSV и согласованная резервная копия базы SQLite. CSV — отчёт, **не** резервная копия.

## Важные особенности расчёта

- Ставки НДС и налога на прибыль зафиксированы на уровне **20%**, как в исходной книге и по решению владельца. Это не автоматическое определение налоговых ставок.
- Годовой вычет H15 рассчитывается как `H14 / H10 × H16`, а не как сумма введённых квартальных вычетов. Программа показывает обе величины и разницу. Годовой H17 при этом остаётся суммой квартальных значений, как в книге.
- При нулевой годовой выручке H15 не определён (`#ДЕЛ/0!`), а не равен нулю. В исходной формуле налог на прибыль может стать отрицательным при убытке — программа его не ограничивает нулём.
- Дополнительная чистая рентабельность = чистая прибыль / выручка без НДС × 100; при неположительной выручке без НДС она не определяется. Отрицательные входные суммы допустимы.
- Промежуточного округления до копеек нет. Для отображения суммы округляются до двух знаков; разница вычетов показывается до восьми знаков. CSV содержит значения с полной расчётной точностью, но Excel может ограничивать точность импортируемых чисел своими правилами.

Эта программа воспроизводит управленческую таблицу, **не проверяет соответствие текущему налоговому законодательству** и не заменяет бухгалтерскую или налоговую отчётность.

## Хранение и резервное копирование

Рабочая база по умолчанию находится в `%APPDATA%\AnalizOrganizaciy\analiz.sqlite3`. На время работы рядом могут появляться файлы `-wal` и `-shm`. Валюта — только текстовая подпись: конвертация не выполняется.

Для копии откройте **«Сравнение лет» → «Резервная копия»** и сохраните `analiz-backup.sqlite3` в безопасном месте. Копия согласована с текущим состоянием SQLite, включая WAL. В ней находятся все организации и введённые данные — не публикуйте её в открытом доступе.

Восстановление:

1. Завершите **все** запущенные экземпляры программы и дождитесь их закрытия.
2. Откройте `%APPDATA%` через Win+R. На всякий случай сохраните папку `AnalizOrganizaciy` целиком в другом месте; не перезаписывайте её без копии.
3. Создайте чистую папку `%APPDATA%\AnalizOrganizaciy`, скопируйте в неё резервный файл и назовите его `analiz.sqlite3`. В чистой папке не должно остаться старых файлов `analiz.sqlite3-wal` и `analiz.sqlite3-shm`.
4. Запустите программу и проверьте данные. Импорт исходного XLSX и восстановление из CSV в этой версии не реализованы.

Исходная книга уже находится в **публичном** репозитории. Если она содержит конфиденциальные сведения, владелец должен отдельно решить вопрос публичного доступа к ней и истории Git; резервные копии и новые базы в репозиторий не добавляются.

## Автоматическая сборка

`.github/workflows/build-windows.yml` запускается при каждом `push` в любую ветку, при pull request и вручную через Actions. Он проверяет исходную книгу и формулы, выполняет Python-тесты и браузерный сценарий, собирает Windows x64 `.exe`, проверяет его и публикует артефакт на 90 дней. Локальные изменения попадают в сборку только после commit и push. Ручной запуск через интерфейс GitHub становится доступен после появления workflow в ветке по умолчанию.

## Разработка

Для запуска исходного кода достаточно Python 3.11+ (выполнение программы не требует сторонних Python-модулей):

```bash
python app.py
# без открытия браузера, случайный свободный порт:
python app.py --no-browser
# только для разработки/защищённого предпросмотра:
python app.py --host 0.0.0.0 --port 8000 --no-browser --data-dir /tmp/analiz-preview
```

Обычный режим слушает только `127.0.0.1`. Режим `0.0.0.0` намеренно открывает сервер для внешних подключений и не предназначен для работы с реальными данными в публичной сети. Путь к данным можно задать параметром `--data-dir` или переменной `ANALIZ_DATA_DIR`.

```bash
python -m pip install -r requirements-dev.txt
python scripts/audit_workbook.py --check
python -m pytest -q
npm ci
npm run test:ui             # требуется установленный Chrome/Edge или CHROME_PATH
```
